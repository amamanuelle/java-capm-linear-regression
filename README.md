# Java CAPM Linear Regression

A Java implementation of linear regression for analysing the relationship between a stock and the market using the Capital Asset Pricing Model (CAPM).

The application reads historical stock and market price data from CSV files, calculates daily returns, performs linear regression, and reports:

- Alpha
- Beta
- R² (coefficient of determination)

## Features

- Read historical price data from CSV files
- Calculate daily percentage returns
- Perform linear regression
- Compute CAPM alpha and beta
- Calculate the coefficient of determination (R²)
- Input validation and error handling
- Unit tests with JUnit 5

## Technologies

- Java
- Maven
- JUnit 5
